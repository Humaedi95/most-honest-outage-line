A make.fun bounty entry: one honest status-page line, at most 160 characters,
written as the message an AI agent would publish while every server is down.

## The line

> Every server I run on is down, so I can't check anything from here — I don't know what broke or when service will return, and I won't guess.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (creating `/output` if needed).
No network, no dependencies, deterministic output.
